## Quan hệ và hành vi xóa

- Nguồn: Đã có (`prisma/schema.prisma:31-38,65-66,77,100,119,483-504`). Schema chỉ khai báo explicit relation cascade cho UserRole/User Session, EventRecord-Outbox, Subject-Record-Activity; reset dùng `TRUNCATE ... CASCADE` cho toàn bộ inventory nên mọi row application bị xóa dù không có Prisma relation.
- Nguồn: Đã có (`scripts/demo/reset.ts:102-118`, `platform/evidence/storage-adapter.ts:21-39`). Trước truncate, query Evidence metadata path `demoNamespace=civicos-demo`, gọi cleanup storage key an toàn; sau đó row Evidence cũng bị truncate; file ngoài namespace/tile giữ nguyên.
- Nguồn: Đã có (`spec.md:11-18`). Không có migration trong feature; `_prisma_migrations` và schema giữ nguyên; không seed reference row bằng direct insert ngoài command/identity contract được giao.
- Nguồn: Mới (quyết định design ngày 2026-09-29). Verifier kiểm tra quan hệ bằng resource key/type/id allowlist vì nhiều domain child hiện không có Prisma FK; orphan detection không được giao cho database constraint.
