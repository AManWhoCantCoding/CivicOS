# Test skeleton — 05e-verifier-tree-fingerprint-build-checkpoint

- **AC-01:** Input: checkout baseline; output `node scripts/verify.mjs --tree`; chạy `npm run mobile:build`; output `--tree` lần hai; inventory `git ls-files -o --exclude-standard` trước/sau. Expected: hai dòng khớp regex `Tree: [0-9a-f]{8}` và có cùng fingerprint; test lưu được các generated/untracked path xuất hiện/đổi sau build.
- **AC-02:** Input: chạy `node scripts/verify.mjs 05-mobile-readonly-client --scope=full` với exit `0`, bảy dòng step đều `PASS`; chạy ngay `node scripts/verify.mjs --tree`. Expected: `Tree: <fingerprint>` trong full output/evidence bằng exact output `Tree: <fingerprint>` của invocation độc lập.
- **AC-03:** Input: từng path trong inventory native build, gồm path mới và path chỉ đổi mtime/content. Expected: path generated được nhận diện bằng rule cụ thể hoặc không xuất hiện trong non-ignored input; source/config relevant không bị nhận diện là generated chỉ do prefix chung `mobile/**`/`mobile/android/**`.
- **AC-04:** Input: baseline Tree; sửa lần lượt `mobile/android/settings.gradle`, `mobile/android/app/build.gradle`, `mobile/android/gradle.properties`; tạo/sửa untracked `mobile/android/__05e_probe__/probe-config.gradle`; khôi phục/xóa tất cả. Expected: mỗi sửa relevant làm Tree khác baseline; sau cleanup Tree trở lại exact baseline.
- **AC-05:** Input: `node scripts/verify.mjs 05-mobile-readonly-client --check --scope=mobile`; `--scope=mobile --only=mobile:typecheck`; `--scope=full --check`; một invocation có step fail thật. Expected: danh sách/thứ tự step, exit code, `PASS`/`FAIL`/`NOT_RUN`/`INCOMPLETE`, `RESULT` và việc command thật được thực thi giống baseline; không có assertion cho phép skip/exclude/bypass.
- **AC-06:** Input: `git diff --name-only` sau implementation và kết quả regression test. Expected: chỉ `scripts/verify.mjs` và `tests/tooling/verify-tree-fingerprint.test.ts` ngoài evidence workflow; không có path product/mobile/native/dependency/lockfile/ticket 05; regression pass với actual checks nguyên vẹn.
