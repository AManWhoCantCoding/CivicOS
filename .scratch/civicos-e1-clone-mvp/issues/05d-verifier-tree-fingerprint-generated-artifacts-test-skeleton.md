# Test skeleton — 05d-verifier-tree-fingerprint-generated-artifacts

- **AC-01:** Input: cùng checkout; snapshot `node scripts/verify.mjs --tree`; tạo/cập nhật file giả lập dưới `mobile/android/app/build/**` và `mobile/android/build/**` hoặc chạy mobile build tạo artifact; chạy lại `--tree`. Expected: hai fingerprint giống hệt nhau khi không sửa source/config relevant.
- **AC-02:** Input: môi trường mobile đã PASS; chạy `node scripts/verify.mjs 05a-mobile-build-boundary-fix --scope=mobile`, sau đó chạy `node scripts/verify.mjs --tree`. Expected: command profile exit `0`, các step được chọn đều `PASS`, và `Tree <fingerprint>` trong lần PASS bằng fingerprint standalone ngay sau đó.
- **AC-03:** Input: snapshot Tree; sửa một tracked source/config relevant ngoài thư mục build, chạy `--tree`; tạo/sửa một untracked non-ignored source/config relevant ngoài thư mục build, chạy `--tree` lần nữa. Expected: mỗi thay đổi relevant làm fingerprint khác snapshot tương ứng; path source/config không bị filter.
- **AC-04:** Input: tập path fingerprint sau patch gồm `mobile/android/app/build/**`, `mobile/android/build/**`, `mobile/android/settings.gradle`, `mobile/android/app/build.gradle`, `mobile/android/gradle.properties` và source/config ngoài thư mục build. Expected: các path generated/build bị loại; các file source/config còn lại được đưa vào fingerprint.
- **AC-05:** Input: chạy `node scripts/verify.mjs 05a-mobile-build-boundary-fix --check --scope=mobile`, `node scripts/verify.mjs 05a-mobile-build-boundary-fix --scope=mobile --only=mobile:typecheck`, và một invocation có step fail thật. Expected: output/chọn step, mã thoát và trạng thái `PASS`/`FAIL`/`INCOMPLETE` giữ nguyên baseline; verifier vẫn chạy check/test/build thật, không có skip/exclude/bypass.
- **AC-06:** Input: `git diff --name-only` của implementation và kết quả regression test. Expected: chỉ có `scripts/verify.mjs` và `tests/tooling/verify-tree-fingerprint.test.ts` (ngoài evidence workflow) trong changed paths; không có production/mobile behavior, dependency, lockfile, business source, hoặc thay đổi ticket `05a`/`05b`/`05c`; test không chứa assertion skip/exclude check thật.
